This is an archipellago Radomizer mod for the game ICEwall. you can find its corisponding APworld [here](https://github.com/System-of-Root/ICEwallAPword/releases).

## Installation Instructions
Download and install mellonloader V0.7 from [https://melonloader.co/download.html](https://melonloader.co/download.html)

Then downaload the latest relase of the mod and extract the `Mods` and `UserLibs` folders into ICEwall's instlation directory `Steam Library/steamapps/common/ICEwall`


### Using the mod
After installing the mod and oppening ICEwall, you should see a connection window in the top left of the screen. Fill in the appropriate data for your game, then click `New` if this is your first time connecting to the multiworld, or `Continue` if you have already connected to it before. 

Once the menu closes you can begin playing. If the menu doesnt close, check mellon's console for errors.
